2. DOCKER ARCHITECTURE (DOCKERFILE OR DOCKER COMPOSE?)
--------------------------------------------------------------------------------
You will use BOTH together:

A) A "Dockerfile":
   - Builds a custom PHP 8.3 FPM image.
   - Installs required Symfony extensions: pdo_mysql, intl, opcache, zip.
   - Embeds Composer directly inside.

B) A "docker-compose.yml":
   - Orchestrates the 3 core services:
     1. "php" service: Runs Symfony 7.4 and CLI commands (migrations, fixtures, tests).
     2. "web" service (Nginx): Serves the web app on http://localhost:8000.
     3. "database" service (MySQL 8.0): Persists relational data in a Docker volume.

C) HOW YOU WORK DAILY VIA DOCKER:
   - Start the environment:
     docker compose up -d
   - Run a Symfony console command:
     docker compose exec php bin/console make:entity
     docker compose exec php bin/console doctrine:migrations:migrate
     docker compose exec php bin/console doctrine:fixtures:load
   - Run automated tests:
     docker compose exec php bin/phpunit
   - Install a package with Composer:
     docker compose exec php composer require symfony/http-client
